# Yetipsy Party · 案件工作室

## 入口
- 案件工作室: /party/studio/
- 玩家解密大厅: /party/studio/play.html
- 原 Party 总入口: /party/
- 旧 CASE 0017: /party/case-0017/ （不覆盖）

## 创建案件
1. 使用管理员密钥登录工作室。
2. 创建案件：填写标题、URL 标识、人数和预计时间。
3. 在「开场剧情」制作多幕解说，可上传图片、视频、音频。
4. 在「调查场景」选择：场景搜证、CCTV 监控、手机、终端、档案、访谈、照片。
5. 在「调查材料」添加有效线索、背景材料或干扰线索，并在图片上点选出现位置。
6. 在「解密机关」添加数字密码、输入指令、选项判断或顺序机关。
7. 在「证据关联」指定两份材料可以形成的有效证明关系。
8. 在「结案判断」设置三个候选答案、正确项和先决证据关联。
9. 在「结局与彩蛋」完整解释本案结局，再设置下一集钩子。
10. 保存草稿，预览，确认后发布。多人玩家从案件馆选择案件开房。

## 数据约定
- 所有场景、资料、机关和证明 ID 必须唯一；建议英文字母、数字、短横线。
- 每条调查材料需要选定所属场景；热点 X/Y 为图片百分比，支持可视化点选。
- 可设置材料为干扰项，标记只在编辑器显示，不向玩家显示。
- 机关答案只在服务器验证；未收集指定材料可阻止机关解锁。
- 证据关联目前固定由两份材料组成，必须靠玩家自行组合。
- 结案题只有形成指定证明后才开放；结案需全体玩家确认。
- 本案的结局与彩蛋在服务器确认结案前不会发送给玩家。

## 支持的媒体
- JPG / PNG / WebP / GIF、MP4 / WebM、MP3 / M4A / WAV / OGG。
- 使用独立 Party 项目的私有 Storage，签名上传；单文件不超过 50MB。
- 作品素材需确保拥有商用与公开展示许可。

## 现阶段功能
- 后台密钥登录、草稿保存、导出/导入 JSON、发布/归档。
- 自由配置开场、场景、原始资料、机关、证明和结案。
- 私有媒体上传、预览素材、点击图片设置热点。
- 玩家案件目录、创建房间、2–6 人手机分工、共享调查进度。
- 在服务端核对密码、验证资料配对和结案答案。
- 无实时 AI API，无付费提示或支付入口。
