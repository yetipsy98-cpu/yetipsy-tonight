YÉ TIPSY PLAY — NO LOGIN DEMO
================================

试玩方式 A（完全不需要 GitHub）
1. 把 play-demo.html 下载到电脑。
2. 双击，用 Chrome / Edge 打开。
3. 顶部切换 顾客、Staff、Owner，直接体验所有功能。

试玩方式 B（部署 GitHub Pages 给自己在手机上试）
1. 打开 github.com/yetipsy98-cpu/yetipsy-tonight
2. 进入 main 分支根目录，不是 play/ 文件夹。
3. Add file -> Upload files -> 选择 play-demo.html -> Commit changes。
4. 打开 https://yetipsy98-cpu.github.io/yetipsy-tonight/play-demo.html

不会覆盖旧 Moon、play/，不需要 Supabase、邮件、API Key 或密码。

操作建议：
1) 顾客：默认有 3 次 Game Pass，任选 5 款游戏试玩。
2) Staff：生成领取码 / 一键模拟顾客领取。
3) 顾客：REWARDS 中生成 60 秒兑奖码。
4) Staff：输入兑奖码，查询并核销。
5) Owner：修改活动、游戏开关、奖池权重及送奖励。

重要限制：
- 所有资料仅存储本机浏览器 localStorage，不会跨手机同步。
- Reward、代码、核销全是演示，不产生任何真实可使用优惠。
- 此文件在 GitHub Pages 上可直接运行，也可下载到电脑双击打开。
- 真正多手机扫码 / 同步 / 登录 / 核销，仍需 Supabase 版完成联调。
- 没有修改或启用正式版的任何数据库或现有网页。
